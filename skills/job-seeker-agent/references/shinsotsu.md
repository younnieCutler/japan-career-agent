# 新卒 track — student-era evidence

新卒 candidates often have limited work history. Use 学チカ, coursework, part-time work, projects,
and volunteering as clearly labelled `student-era evidence`; do not present them as professional
experience.

## Step 1 — collect

Ask for the situation, the candidate's own task, decisions, actions, collaboration, result, and
reflection. A numeric result is optional. If the user cannot verify one, use scope, frequency,
duration, observable change, or learning instead of estimating.

## Step 2 — work-style reflection

The custom 12-statement exercise is `SPI3-inspired reflection`, not official SPI3 or a validated
assessment. Store responses and user-reviewed tendencies; do not use them to declare a company-type
fit. Translate a preference into questions about manager style, decision ownership, feedback,
training, and day-to-day work.

## Step 3 — evidence review

Use the same axes as a mid-career review:

- hard eligibility and authorization: `Confirmed` / `Unknown` / `Contradictory`;
- requirements: `Matched` / `Missing` / `Unknown`;
- values and conditions: `Aligned` / `Tradeoff` / `Conflict` / `Unknown`;
- portable-skill evidence: only what the episode demonstrates;
- missing information and questions to ask the company.

Student evidence can support a preparation recommendation, but one strong episode cannot offset a
confirmed hard conflict. If the JD is absent, say the company-specific comparison is `Unknown`.

## Step 4 — ES and interview material

Structure 学チカ as `Situation → Task → Action → Result → Reflection`. Keep every sentence tied to
the user's episode. For “why this company,” cite company-specific evidence and state what remains
unverified. Do not claim the company type or a reflection trait proves culture.

## Profile handoff

Write a `CANDIDATE_PROFILE` only after review. Keep unassessed fields null; use
`work_style_reflection` for the custom reflection and never create an official-test result.

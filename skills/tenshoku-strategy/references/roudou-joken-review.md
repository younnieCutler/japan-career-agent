# 労働条件通知書 · 雇用契約書 Review (Downgrade Check vs Current Job)

> The final defense line after 年収交渉 (→ `nenshu-koushou.md`) and オファー面談 (→ `naitei-taiou.md`):
> verify the **written** conditions before 承諾. Two comparisons, always both:
> **(a) written offer vs what was said verbally** in interviews / オファー面談, and
> **(b) written offer vs the current job** — item by item, flagging every downgrade (下方).

**Core Principle:** A negotiation won verbally can still be lost on paper. Never accept (承諾) before the
written 労働条件通知書 arrives and passes this review. No encouragement; deliver the comparison table.

**Not legal advice.** Basis: 労働基準法15条 (employer must state working conditions in writing),
労働契約法. For disputes, route to 労働局の総合労働相談コーナー or a lawyer.

---

## 1. Document Taxonomy — know which paper you are holding

| Document | Legal weight | What it is |
|----------|-------------|------------|
| 内定通知書 | Notice only | Says "you passed." Conditions often absent or summary-level. |
| 労働条件通知書 | **Legally required** (労基法15条) | Unilateral written statement of conditions. The reviewable artifact. |
| 雇用契約書 / 労働条件通知書兼雇用契約書 | Contract (both parties sign) | Same content + your signature. Review BEFORE signing. |

**Rules:**
- If only a 内定通知書 arrived → request the 労働条件通知書 before answering. Script:
  > 「承諾のお返事の前に、労働条件通知書（書面）をご共有いただけますでしょうか。」
- An employer that stalls on issuing written conditions is itself a red flag (→ §4).
- Absolute-必須 items the notice must state: 契約期間 / 就業場所 / 業務内容 / 労働時間・休日 / 賃金 /
  退職に関する事項. Missing items → ask, in writing.

---

## 2. Downgrade Comparison Table (現職 vs オファー)

Collect the current job's real numbers first (payslip / 就業規則 / 雇用契約書 — not memory).
Then compare every row. Verdict per row: `↑ improved` / `→ equal` / `↓ downgrade`.

| # | Item | What to compare exactly | Common trap |
|---|------|--------------------------|-------------|
| ① | **年収 decomposition** | 基本給 / 固定残業代 / 賞与 / 諸手当 — separately, not the total | Same 年収 but lower 基本給 → 賞与・残業単価・退職金の算定基礎 all shrink invisibly |
| ② | **固定残業代 (みなし残業)** | Included hours + whether excess is paid | 45h included = ~2h/day overtime priced in. 「超過分は別途支給」の明記 absent → NG |
| ③ | **賞与** | Fixed months? 業績連動? Last actual payout (前年実績) | 「業績による」 with no 実績 disclosed = treat as 0 for comparison |
| ④ | **年間休日** | Days count + 完全週休2日 vs 週休2日 | 週休2日制 = *some* weeks have 2 days off. 105日 vs 現職120日 = −15 days/year |
| ⑤ | **試用期間** | Length + whether conditions differ during it | Lower salary or 契約社員 status during 試用期間 — must be stated; verify the after-period terms too |
| ⑥ | **就業場所 · 転勤** | Fixed location? 転勤条項? Remote policy in writing | Verbal "remote OK" + written 「会社の定めによる」 = the written text wins |
| ⑦ | **労働時間** | 始業終業 / フレックス (コアタイム) / 裁量労働制の有無 | 裁量労働制 = overtime concept largely disappears; confirm the みなし時間 |
| ⑧ | **評価・昇給** | Cycle, first review timing, criteria | Negotiated "6-month re-review" (→ `naitei-taiou.md` §7) must appear in writing or a confirmed mail |
| ⑨ | **退職金 · 企業型DC** | Existence, vesting, employer match | 現職に退職金あり → オファー側になし is a real 年収-equivalent downgrade; quantify it |
| ⑩ | **競業避止 · 副業** | 競業避止義務の範囲/期間, 副業可否 | Overbroad 競業避止 constrains the *next* 転職; 現職で副業可 → 不可 is a downgrade |
| ⑪ | **社会保険 · 福利厚生** | 加入保険, 家賃補助, 通勤手当上限 | 手当 loss can silently offset a base raise |

### Output format (mandatory)

```
■ 条件比較 (現職 vs オファー) — 書面基準
| 項目 | 現職 | オファー(書面) | 判定 |
|------|------|---------------|------|
| 基本給 | 32万 | 30万 | ↓ |
| 固定残業代 | なし | 45h込み | ↓ |
| 年間休日 | 125日 | 120日 | ↓ |
| ...
■ 下方項目: N件 — [list with the concrete delta]
■ 口頭との相違: [オファー面談で言われた内容 vs 書面 — discrepancies]
■ 総合判定: [承諾可 / 承諾前に要確認・要交渉 N件 / 重大な下方 — 再考推奨]
```

- Every ↓ row must show the **concrete delta** (−2万/月, −15日/年), not just the arrow.
- If the user cannot provide a current-job figure, mark the row 比較不可 — do not guess.

## 3. When the written offer contradicts the verbal one

Discrepancy between オファー面談 statements and the 書面 is common and recoverable — if raised **before**
承諾, politely, as a confirmation (not an accusation):

> 「オファー面談では〇〇とご説明いただいたと認識しておりますが、通知書では△△となっております。
> 私の理解違いでしたら恐縮ですが、確認させていただけますでしょうか。」

- Via agent → raise it through the CA first (→ `naitei-taiou.md` §5).
- If they correct the paper → resolved. If they say "the paper is right" → re-run §2 with the real numbers
  and re-judge. A company that walks back offer-meeting statements is data about the company.
- Any verbally-agreed condition that matters (re-review timing, remote days, 入社日) → get it in the
  通知書 or at minimum a confirmation **mail**. 「言った言わない」has no winner.

## 4. Red Flags (structural — point out directly)

| Signal | Why it matters |
|--------|----------------|
| 固定残業代 45h+ (60h = severe) | Long-hours culture priced into the salary |
| 試用期間中の条件引き下げ + 期間6ヶ月超 | Extended low-cost probation |
| 年俸制で残業扱いが不明記 | 年俸制 does NOT legally erase overtime pay — absence of clarity is the flag |
| 賞与「業績による」+ 実績非開示 | Effective comp likely below the quoted 想定年収 |
| 労働条件通知書の発行を渋る / 承諾を急かす | 労基法15条 obligation being dodged + pressure tactic |
| 書面がオファー面談の説明より一律に悪い | Systematic, not clerical |

Two or more flags → state plainly: "承諾前に書面での解消が必要です。解消されない場合、この条件差は
入社後に是正される見込みは低いです。"

---

## Honesty Gate

- Do not tell the user a downgrade is "acceptable because of growth opportunity." Quantify the delta;
  the trade-off judgment is the user's (route value questions to `company-battlecard`).
- Do not compare against an inflated memory of current conditions — require the payslip/契約書 figures.
- Renegotiation requests after 承諾 have near-zero leverage. State this before, not after.

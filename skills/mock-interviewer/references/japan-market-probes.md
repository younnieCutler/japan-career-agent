# Japan-market interview probes

Load this reference only when the practice topic includes short tenure, an employment gap, weakness, self-introduction, or AI-assisted application text. These are question-generation rules, not hiring forecasts.

## Short tenure

Keep four inputs separate:

- tenure length actually documented;
- number and pattern of transitions;
- candidate's factual reason for each move;
- confirmed work evidence from the period.

A short tenure may justify a retention-risk question, especially when repeated. It is not an automatic failure and there is no universal three-year minimum. Do not convert the 9.5-month survey average into a cutoff.

Useful probes:

- 「在籍期間が短いですが、退職を決めた具体的な背景を教えてください。」
- 「同じ状況が次の職場でも起きた場合、今回はどう判断しますか？」
- 「その期間に担当したこと・残した成果で、確認できるものは何ですか？」

## Employment gap

Preserve these as separate facts:

```text
employment_gap: present / absent / unknown
gap_length: confirmed period or Unknown
gap_activity: study / care / travel / rest / job search / other / Unknown
gap_explanation: candidate's factual explanation or Unknown
career_relevance: verified / unknown
```

Certification study, education, care, travel, or rest does not erase the gap. Probe what the candidate actually did and what, if anything, is relevant to the target role. Do not assign a fixed penalty.

## Weakness

Do not blacklist trait labels such as `頑固`. Probe:

```text
weakness -> observed downside -> mitigation behavior -> evidence of improvement
```

If the weakness conflicts with a confirmed hard requirement, preserve that conflict. Mitigation does not erase it.

## Self-introduction

Prefer a concise career-relevant hook from confirmed experience. A novelty hobby is not required as bait. If the user wants to include a hobby because it is genuinely relevant to them, keep it as user-owned content, not an interview-control tactic.

## AI-assisted text

AI use is not proof of deception. Test defendability instead:

- Can the candidate explain every factual assertion?
- Does each metric have a source?
- Can the candidate answer a counterexample or follow-up without inventing detail?

Remove unsupported material rather than coaching the candidate to evade AI detection.

# Company Battlecard 참조 프레임워크

이 파일은 `company-battlecard` 스킬이 기업 비교 시 참조하는 프레임워크입니다.
전체 프레임워크는 `job-seeker-agent/references/frameworks.md`에 있습니다.

---

## 1. SPI3 × 기업 유형 매칭 기준

| 기업 유형 | 최적 SPI3 조합 | 비적합 SPI3 |
|-----------|---------------|------------|
| 스타트업 / 자사 개발 | 창조(Creation) + 결과(Result) | 질서(Order) 단독 |
| SIer / 대기업 SI | 질서(Order) + 조화(Harmony) | 창조(Creation) 단독 |
| 외자계 / 컨설팅 | 결과(Result) + 창조(Creation) | 조화(Harmony) 단독 |
| 에이전시 / 마케팅 | 창조(Creation) + 조화(Harmony) | 질서(Order) 단독 |
| 중견 SaaS | 결과(Result) + 질서(Order) | 조화(Harmony) 단독 |
| SES (기술 파견) | 질서(Order) + 조화(Harmony) | 창조(Creation) + 결과(Result) |

## 2. 하타라쿠 웰빙 (Hataraku Well-being) 지수

| 요소 | 일본어 | 정의 | 높을 때 적합한 기업 유형 |
|------|--------|------|------------------------| 
| 자기 결정감 | 自己決定感 | 업무 방식/내용을 스스로 선택할 수 있는 실감 | 스타트업, 자율 근무 IT 기업, 리모트 환경 |
| 사회 공헌감 | 社会貢献感 | 자신의 일이 타인/사회에 도움이 된다는 느낌 | B2C 서비스, 사회적 기업, 교육/헬스케어 |
| 상사 매니지먼트 | 上司のマネジメント | 긍정적 피드백, 경청, 공정한 평가 | 1on1 문화, 코칭형 리더십 조직 |
| 조직 내 상호 존중 | 組織内の相互尊重 | 동료 간 존중과 협력 분위기 | 애자일 팀, 플랫 조직, 심리적 안전성 높은 팀 |

### 매칭 판정

| 일치도 (4요소 차이 합계) | 판정 |
|------------------------|------|
| 0~4 | 매우 적합 (High Fit) |
| 5~8 | 보통 (Medium Fit) |
| 9 이상 | 부적합 (Low Fit) — 조기 퇴사 리스크 |

## 3. 기업 평가 시그널 가이드

JD나 기업 정보에서 추출할 수 있는 문화 시그널 목록입니다.
데이터가 없으면 추측하지 말고 "N/A"로 처리하세요.

| 시그널 | 읽는 법 | 주의점 |
|--------|---------|--------|
| "자주적으로 움직이는 인재" | 자율성 높음 but 교육 체계 없을 수 있음 | 신입에게는 방치 리스크 |
| "チーム一丸となって" | 팀워크 중시 but 개인 성과 불명확할 수 있음 | Order+Harmony 적합 |
| "裁量権が大きい" | 의사결정권 있음 | 책임도 큼 — Result 높아야 |
| "残業月20時間以内" | WLB 의식 있음 | 실제 준수 여부는 OpenWork 확인 |
| "フルリモート可" | 자율성 높음 | 온보딩 품질 확인 필요 |
| "年功序列ではなく実力主義" | Result 중심 평가 | 안정성 낮을 수 있음 |
| 평균 근속 연수 3년 미만 | 이직률 높음 | 성장 기회 OR 소진 환경 |
| 평균 근속 연수 10년+ | 안정적 but 보수적 | Order+Harmony 적합 |
